# 🔋 12V Regulated DC Power Supply

A complete analog electronics project involving the design, PCB fabrication, hardware implementation, and testing of a **12V Regulated DC Power Supply**.

The project converts AC mains voltage into a stable regulated 12V DC output using a step-down transformer, bridge rectifier, capacitor filter, and Zener diode voltage regulator. It demonstrates practical knowledge of power electronics, PCB design, circuit analysis, and hardware implementation.

---   

## 📌 Project Overview      
  
This project was developed as part of the Electronic Devices and Circuits course.   

The objective was to design and fabricate a reliable regulated DC power supply capable of delivering a stable 12V DC output suitable for powering electronic circuits.        

---

- ✔ Step-down AC transformer

## ⚙ Components Used  

| Component | Purpose |
|-----------|----------|
| Step-down Transformer | Converts 220V AC to low AC voltage |
| Bridge Rectifier | Converts AC into pulsating DC |
| Electrolytic Capacitor | Reduces ripple voltage |
| Zener Diode | Maintains constant output voltage |
| Resistors | Current limiting and biasing |
| LED Indicator | Output indication |
| PCB | Hardware implementation |

---

## ⚡ Working Principle

The transformer first reduces the AC mains voltage.

The bridge rectifier converts AC into pulsating DC.

A large electrolytic capacitor smooths the rectified output by minimizing ripple.

Finally, the Zener diode regulator maintains a constant 12V DC output regardless of minor variations in input voltage or load conditions.
